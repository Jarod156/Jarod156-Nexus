# NEXUS v0.2.0 — version navigateur simple

Cette version fonctionne avec un seul fichier principal `index.html`.

## GitHub

Téléversez simplement à la racine du dépôt :

- `index.html`
- `netlify.toml`
- `README.md`

## Netlify

Le fichier `netlify.toml` indique à Netlify de publier directement la racine du dépôt.

## Limitation actuelle

Les PDF sont enregistrés dans le navigateur local. La synchronisation partagée sera ajoutée plus tard avec Supabase.
